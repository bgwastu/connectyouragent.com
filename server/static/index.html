Connect Your Agent

GitHub

Give Claude Code, Codex, OpenClaw, or custom AI agents temporary, user-approved shell access to your machine without opening inbound ports or sharing SSH credentials.

How It Works
  • 1. Click Create Session to get an install command.
  • 2. Run the command on the target machine to connect.
  • 3. Paste the prompt into your AI agent (Claude Code, Codex, etc.).
Privacy & Security
  • 100% In-Memory: Sessions, metadata, and commands exist strictly in volatile RAM. Nothing is ever saved to disk or a database.
  • Zero Logging: No command history, outputs, or credentials are saved or tracked on server infrastructure.
  • Ephemeral & Revocable: Disconnecting immediately closes the bridge and destroys the session. Sessions automatically self-destruct when idle.
